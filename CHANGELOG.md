## 0.1.0 - 2026-08-14

### Added

- Initial `sleep-with-me` skill for brief, low-stimulation nighttime support.
- Initial `dont-text-them` skill for adding friction before impulsive messages.
- Initial `stop-the-spiral` skill for separating facts, unknowns, interpretations, and fears.
- Cross-agent installation instructions and a Claude Code marketplace bundle.
- Deterministic `.skill` package generation.
- Repository validation, documentation-link checks, safety tests, and CI.
- Design, safety, contribution, security, and Traditional Chinese documentation.
